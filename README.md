# IFRS17_Insurance-Liability-Model

## 프로젝트 개요
Excel VBA와 Python을 활용한 IFRS17 보험부채평가 모델 포트폴리오

## 기술
Excel VBA, Python(xlwings)

## 개발 목적
- 보험수리 이론을 실제 계산 모형에 적용하여 직무 이해도 향상
- Excel VBA와 Python을 활용한 보험계리 데이터 처리 및 계산 자동화 역량 강화
- 계리가정 변화에 따른 보험부채와 수익성 변동 분석

## 사용 기술
- Excel VBA: 보험계약 조건 입력 및 계산 실행
- Python(xlwings, pandas, numpy): 현금흐름 및 보험부채 계산
- 데이터: 제10차 완전생명표(2023)

## 주요 구현 기능
1. 보험계약 조건 및 계리가정 입력
2. 사망률·생존율을 반영한 보험료, 보험금, 사업비 등 현금흐름 산출
3. 최선추정부채(BEL), 위험조정(RA), 이행현금흐름(FCF), 보험계약서비스마진(CSM) 계산
4. 할인율 및 해약환급금 변화에 따른 민감도 분석
5. 계산 결과의 Excel 자동 출력 및 시각화

## 실행 과정
1. `IFRS17_CSM_portfolio.xlsm` 실행
2. 입력 시트에서 성별, 가입연령, 보험기간, 보험료 등 조건 입력
3. 데이터 불러오기 및 계산 실행 버튼 클릭
4. 결과출력 시트에서 보험부채 산출 결과 확인

## 결과물
- 보험료·보험금·해약환급금·사업비 현금흐름
- BEL·RA·FCF·CSM 및 보험계약부채
- 할인율·해약환급금 민감도 분석 그래프
- 보험부채 평가 요약 보고서
