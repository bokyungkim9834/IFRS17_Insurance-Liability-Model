# IFRS17_Insurance-Liability-Model

## 프로젝트 개요
Excel VBA와 Python을 활용한 IFRS17 보험부채평가 모델 포트폴리오
## 기술
Excel VBA, Python(xlwings)
## 포트폴리오를 만드는 목적?
실무에 빠르게 적응하기위한 역략 기르기, 계리사2차 공부의 이해도 향상과 동기부여 자극
## 기대
스스로 계산로직을 구현하면서 데이터를 처리하고 분석하는 능력 기르기
## 이 주제를 선정한 이유?
보험수리학을 공부하면서 공부내용과 밀접한 주제 선정, 실제 축약된 계리업무매커니즘을 경험할 기회제공
## 구현 순서
통계데이터 수집-> 현금흐름에 반영할 조건입력(VBA) -> 계산로직 설계(Python) -> 결과 값 자동산출 
## 구현내용
BEL, RA, CSM, 보험계약부채, 민감도 분석
1. 엑셀 입력 시트에서 조건입력(성별, 나이, 보험기간, 보험료) 후 [정보입력버튼] 클릭
2. 자동으로 데이터시트에서 입력된 정보기준으로 할인율, 사업비율 등이 입력됨
3. 계산시트에서 [계산 결과출력 확인]버튼을 클릭하면 자동산출됨
## 결과
결과출력시트에 보험료, 보험금, 해약환급금, 직접사업비, BEL, RA, FCF, CSM, 보험계약부채 값 출력, 주요가정 변화에 따른 민감도 분석 완성
